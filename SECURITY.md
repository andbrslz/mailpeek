# Security policy

Mailpeek is a development and testing tool. It is not meant to be exposed to the internet; see the [Security section of the README](README.md#security) for what it does to stay safe on shared machines.

## Supported versions

Security fixes go into the latest minor release.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/andbrslz/mailpeek/security/advisories/new), not in a public issue. Include the version (`mailpeek version`), how to reproduce it and the impact you expect.

You can expect a first answer within a week. Once a fix is released, the advisory is published with credit to the reporter, unless you prefer otherwise.
